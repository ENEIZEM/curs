# ASSEMBLY / FIELD MANUAL

Интерактивный образовательный курс по теме **«Сборка персонального компьютера»** на чистом HTML/CSS/JS.

## Запуск

Откройте `index.html` в современном браузере. Интернет, npm и сервер не требуются. Проект не отправляет данные и не загружает внешние библиотеки.

## Состав

- `index.html` — основной плеер с 26 кадрами и семью модулями.
- `labs/lab-01.html` … `labs/lab-09.html` — отдельные страницы для подготовки скриншотов. Каждая страница ограничена механиками своей лабораторной.
- `css/course.css`, `js/course.js` — общая система оформления и интерактивности.
- `assets/course-structure.svg` — схема иерархии курса.
- `assets/build-scenario.svg` — технологический сценарий со штатными и условными переходами.
- `assets/slide-plan.csv` — план из 26 кадров.

## Функции

Навигация «Назад/Далее», содержание, индикатор прогресса, карточки компонентов, проверка типовых связок совместимости, чек-листы, анимация подсказок, переменные/блокировка перехода в режиме ЛР6, интерактивная карта, три вида тестов и финальный интерактивный стенд.

## Технические оговорки

- Виртуальный стенд — упрощённая интерактивная SVG-визуализация, не физически точная 3D-модель.
- POST представлен учебной симуляцией и не управляет реальным компьютером.
- Страница публикации формирует демонстрационный `imsmanifest.xml`. Сам по себе XML не является полным SCORM ZIP-пакетом: для настоящего LMS-пакета необходима корректная упаковка ресурсов и интеграция API.
- Исходные отчёты не включены в изменения: их текст остаётся зафиксированным отдельно.
