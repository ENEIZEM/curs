# Сборка персонального компьютера — учебный курс

Автономный интерактивный курс на HTML, CSS и JavaScript. Главная страница — `index.html`; отдельные страницы лабораторных — `labs/lab-01.html` … `labs/lab-09.html`.

## Запуск
Откройте `index.html` в современном браузере. Интернет, npm и сервер не требуются.

## Организация учебного интерфейса
- Верхняя полоса показывает семь этапов курса и общий прогресс.
- Слева находится иерархическое содержание: модули и уроки.
- Центральная область содержит объяснение, иллюстрацию и/или практическое действие.
- На интерактивных экранах всегда есть инструкция и обратная связь.
- Внизу находятся кнопки «Назад» и «Далее». В двух контрольных точках переход заблокирован до выполнения явных проверок.

## Содержание
Курс состоит из 26 уроков в семи разделах: введение, комплектующие, совместимость, подготовка, сборка, первый запуск, проверка знаний.

Поддержаны выбор ответа, сопоставление, упорядочивание, короткий ответ, интерактивная схема разъёмов, контрольные списки и пошаговые объяснения.

## Лабораторные страницы
Каждая страница `labs/lab-XX.html` содержит три сцены для фиксации разных состояний интерфейса. Функции страницы соответствуют теме конкретной лабораторной.

## Технические ограничения
- Схемы материнской платы и компонентов являются условными учебными иллюстрациями, не заменяют инструкции производителя и не являются точной моделью конкретного оборудования.
- Проверки ответов в коротком тексте служат для самопроверки и не заменяют преподавательскую оценку.
- Страница ЛР9 объясняет состав публикации и SCORM, но не формирует готовый SCORM ZIP-пакет и не подтверждает его работу в LMS.
- Тексты академических отчётов хранятся отдельно и не изменялись этим обновлением.
